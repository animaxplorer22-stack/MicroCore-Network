FILE 1: NODE + EMBEDDED MINER (node_full.py)
═══════════════════════════════════════════════════════════════════════════════

DEPENDENCIES:
─────────────────────────────────────────────────────────────────────────────
pip install websockets cryptography requests dnspython

HOW TO RUN:
─────────────────────────────────────────────────────────────────────────────
# First node (creates blockchain)
python3 node_full.py --genesis

# Additional nodes (join existing network)
python3 node_full.py --peer 192.168.1.100:8081

# Run node without mining (node only)
python3 node_full.py --genesis --no-miner

WHAT IT DOES:
─────────────────────────────────────────────────────────────────────────────
- Creates genesis block (only first node)
- Manages blockchain and consensus (PoMA + PoS)
- P2P sync with other nodes (port 8081)
- DNS seed discovery for auto peer finding
- DEX bridge for token swaps with MCX fees
- Embedded miner (auto-starts, mines on your behalf)
- WebSocket server for miners (port 8080)
- Level system (100 MCX per level)
- Slashing (10% penalty for missed signatures)
- Reward distribution (75% validators / 8% nodes / 7% uptime / 10% LP)
- 100M hard cap, 100 MCX reward, 4-year halving

FILE 2: ESP32/ESP8266 MINER (esp_miner.ino)
═══════════════════════════════════════════════════════════════════════════════

HARDWARE REQUIRED:
─────────────────────────────────────────────────────────────────────────────
- ESP32 or ESP8266 board
- USB cable
- Computer with Arduino IDE

ARDUINO IDE SETUP:
─────────────────────────────────────────────────────────────────────────────
1. Install Arduino IDE from arduino.cc
2. File → Preferences → Additional Boards URLs
   Add: https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
3. Tools → Board → Boards Manager → Search "ESP32" → Install
4. Tools → Board → ESP32 Dev Module
5. Tools → Port → Select your COM port

LIBRARIES TO INSTALL (Sketch → Include Library → Manage Libraries):
─────────────────────────────────────────────────────────────────────────────
- WebSockets by Markus Sattler
- ArduinoJson by Benoit Blanchon

EDIT BEFORE UPLOADING (find these lines in the code):
─────────────────────────────────────────────────────────────────────────────
const char* WIFI_SSID = "your_wifi_ssid";
const char* WIFI_PASSWORD = "your_wifi_password";
const char* USERNAME = "your_username";
const char* PRIVATE_KEY_HEX = "your_64_char_private_key_hex_here";

GENERATE PRIVATE KEY (on computer):
─────────────────────────────────────────────────────────────────────────────
openssl ecparam -name secp256k1 -genkey -noout -out private.pem
openssl ec -in private.pem -text -noout | grep -A 3 "priv:" | tail -3 | tr -d ' \n:'

UPLOAD STEPS:
─────────────────────────────────────────────────────────────────────────────
1. Connect ESP32 via USB
2. Select correct Board and Port
3. Click Upload (→ arrow button)

FILE 5: WIFI BRIDGE (wifi_bridge.py)
═══════════════════════════════════════════════════════════════════════════════
(for Arduino Uno - runs on computer)

DEPENDENCIES:
─────────────────────────────────────────────────────────────────────────────
pip install pyserial websockets dnspython

FIND ARDUINO PORT:
─────────────────────────────────────────────────────────────────────────────
python -c "import serial.tools.list_ports; print([p.device for p in serial.tools.list_ports.comports()])"

HOW TO RUN:
─────────────────────────────────────────────────────────────────────────────
# Replace COM3 with your actual port
python3 wifi_bridge.py

WHAT IT DOES:
─────────────────────────────────────────────────────────────────────────────
- Bridges Arduino Uno (Serial) to WebSocket
- Auto node discovery via DNS seeds
- Failover to backup nodes

FILE 6: RASPBERRY PI PICO W MINER (pico_w_miner.py)
═══════════════════════════════════════════════════════════════════════════════

HARDWARE REQUIRED:
─────────────────────────────────────────────────────────────────────────────
- Raspberry Pi Pico W
- USB cable

INSTALL MICROPYTHON:
─────────────────────────────────────────────────────────────────────────────
1. Download MicroPython UF2 from raspberrypi.com
2. Hold BOOTSEL button on Pico
3. Connect USB
4. Drag UF2 file to RPI-RP2 drive

UPLOAD USING THONNY (easiest):
─────────────────────────────────────────────────────────────────────────────
1. Install Thonny from thonny.org
2. Connect Pico W via USB
3. Copy code to Thonny
4. File → Save as → main.py
5. Click Run

EDIT BEFORE UPLOADING:
─────────────────────────────────────────────────────────────────────────────
WIFI_SSID = "your_wifi_ssid"
WIFI_PASSWORD = "your_wifi_password"
USERNAME = "your_username"
PRIVATE_KEY = "your_64_char_private_key_hex"

FILE 7: PHONE MINER (phone_miner.py)
═══════════════════════════════════════════════════════════════════════════════

iPhone (a-shell) - Install a-shell from App Store:
─────────────────────────────────────────────────────────────────────────────
python3 -m ensurepip
python3 -m pip install websockets requests
cat > phone_miner.py
# Paste code, then Ctrl+D
python3 phone_miner.py

iPhone (iSH) - Install iSH from App Store:
─────────────────────────────────────────────────────────────────────────────
apk update
apk add python3 py3-pip
pip3 install websockets requests
cat > phone_miner.py
# Paste code, then Ctrl+D
python3 phone_miner.py

Android (Termux) - Install Termux from F-Droid:
─────────────────────────────────────────────────────────────────────────────
pkg update && pkg upgrade
pkg install python
pip install websockets requests
cat > phone_miner.py
# Paste code, then Ctrl+D
python phone_miner.py

SIMPLE VERSION (No Dependencies - Use if pip fails):
─────────────────────────────────────────────────────────────────────────────
cat > phone_miner_simple.py
# Paste simple code, then Ctrl+D
# Edit NODE_IP line to your node's IP
python3 phone_miner_simple.py

FILE 8: WEB WALLET + MINER (wallet.html)
═══════════════════════════════════════════════════════════════════════════════

DEPENDENCIES:
─────────────────────────────────────────────────────────────────────────────
None - just a web browser

HOW TO USE:
─────────────────────────────────────────────────────────────────────────────
1. Save as wallet.html
2. Open in any browser (Chrome, Safari, Firefox)
3. Create wallet (enter username + password)
4. Enter node URL (ws://YOUR_NODE_IP:8080)
5. Click "Start Mining"

FEATURES:
─────────────────────────────────────────────────────────────────────────────
- Username/password login
- IP tracking (one wallet per IP)
- MCX balance display
- Send MCX (by username, not address)
- Transaction ID for each send
- Stake/Unstake with confirm modal
- Liquidity box (liquidity provided + fees collected)
- Provide Liquidity button (MCX + USDC fields)
- Miner uptime meter (0h-24h progress bar)
- Mined counter (blocks today)
- Missed counter (resets daily)
- Onboarded Nodes section
- Onboarded Miners section
- Built-in Web Miner (toggle switch)
- Mining log (real-time)
- Transaction history
- Exchanges section (Uniswap, PancakeSwap, Raydium)
- Logout button
- Export wallet (JSON download)
- Professional blue/white theme
